# 本地字体与来源

- Literata（可变字体，未修改）：https://github.com/google/fonts/tree/main/ofl/literata 。许可见 Literata-OFL.txt。
- LXGW WenKai / 霞鹜文楷 Regular，v1.530（未修改）：https://github.com/lxgw/LxgwWenKai/releases/tag/v1.530 。许可见 WenKai-OFL.txt。

两种字体均按 SIL Open Font License 1.1 分发，保留版权与许可文本。应用中内嵌本地字体，不需要联网调用字体CDN；不使用 Anthropic 的专有字体、商标或插画。

参考站点：https://www.anthropic.com/ 。仅作为用户指定的暖纸色、阅读排版方向参考。
