# 错题本：收录、整理、复讲与复测

## 使用入口
课堂底部仍可收录整题或选中文字。点击“打开错题本”进入独立管理面板。

1. 点击条目的“整理与复测”，填写考点和专题。
2. 展开“班级与学生”，输入班级；名单每行一名，留空则创建全班共性记录。同一题可以同时有班级汇总和多个学生记录。
3. 每份记录独立填写错因、典型错答、备注、实际错误/参与人数、复习日期和复测。点击“保存条目与记录”后才落盘。
4. 使用学科、班级、学生、时间和到期状态筛选。搜索可匹配来源、考点、专题和错因。多选条目后可批量加入专题。
5. 展开“复讲与输出”，调整条目顺序，选择材料、题面、答案和匿名错答，放映或输出 PPTX/PDF。

## 学生版与教师版
旧条目原有文字不会被猜拆。整理时补充“学生版题面”“共用阅读材料”“教师版答案与讲解”。原收录快照保留。
勾选“已核对内容”后才可复讲；学生版还须确认题面、材料和图片不泄露答案。学生版排除答案模块、错答模块及对象名单，并提供 PDF 作答区；教师版保留所选讲解。两种放映及 PPT 都使用同一分页结果。PDF 为 A4 讲义，可以在 PDF 阅读器中打印。
管理面板包含学生姓名；投屏前请进入专题放映。单屏环境下，管理面板并不是私密教师屏幕。

## 内容与演练
新收录的正文和讲义片段保留来源定位，可检查来源当前内容；较早收录且没有定位信息的旧片段需重新收录。若选中文字已从来源移除，会提示重新选择，不自动拼接替代内容。
检查原题更新可对照当前题面和讲解，并主动采用到工作副本，原收录快照不变。语文整题保留关联材料中的原页图片，亦可上传 PNG/JPEG 补充图片。
“收录已有考点演练”读取原课件的本题演练。“生成并收录关联演练”使用原课件当前题面和已配置服务；需要 API 凭据。失败不收录旧结果。新条目默认待核对；语文练习需教师整理学生版题面，避免凭标签猜测答案边界。可手动关联已有条目；复测可选择原题或关联变式。

## 复习与数据边界
已讲评、教师确认掌握和实际复测结果分开保存。复测历史追加后不可覆盖删除。支持指定复习日期或选择 1/3/7/14/30 天固定间隔；这不是 FSRS 自适应调度。
统计只反映录入数据，班级汇总与个人记录不合并算错误率，缺失人数不推测。得分和人数超出有效范围会阻止保存。
归档可恢复。重复收录提示补充既有对象记录。过期页面保存会提示刷新，避免覆盖新修改。
错题本保存在应用用户数据目录的 notebook.json，升级写入前保留 notebook.json.before-upgrade.json；已有课件数据不迁移。当前课件包不包含独立错题库，换机时需一并备份该文件。
