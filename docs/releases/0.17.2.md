# Lesson Desk 0.17.2

This stable release removes the mistake notebook UI and backend interfaces while preserving existing notebook data. Use the Beta edition if you need the notebook.

## Changes

- Automatically associate chemistry diagrams from PDF and Word papers with their questions. Preserve source images in lesson explanations, presentations, PowerPoint exports and backups.
- Add named AI connections, saved-configuration viewing, connection switching and optional API-key display. Fix back navigation and saving during continued editing.
- Preserve question ranges and task requirements when replacing prompt templates. Revise subject-specific teaching and practice prompts, missing-question recovery, parallel generation and error propagation.
- Include OpenAI Responses and Claude Messages support, page-by-page OCR review, offline LaTeX/mhchem rendering and stable-edition data migration.

## Validation

147 test files and 915 tests passed. Both editions passed build, package-content and isolated-launch checks. PPT/PDF output was exercised. Existing users' installation data and native PowerPoint playback were not covered. Review AI-generated content before use.
