# 讲题工作台 0.18.0

0.18.0 是 Windows x64 正式版，包含课件整理、讲义、课堂放映和 PPT 导出。正式版不含错题本功能，已有错题数据会保留。错题本仍由测试版提供。

## 更新

- 整理、核对、讲义与课堂编排入口更集中。备课时可展开题目与答案，按需查看校对报告和修改记录。
- 英语逐题解析按篇批量生成。失败项目可单独处理，已保存的有效内容可继续使用。
- 新增连续讲评、侧栏板书、逐步揭示三种课堂版式。放映和可编辑 PPT 共用课堂内容和分页逻辑。
- 强化试卷原文与答案关联、生成结果校验和错误提示。对需要重新核对的材料、未就绪的讲义或连接问题明确提示。
- [讲题工作台 Skill](https://github.com/zazedwhwhy/lesson-desk-skill) 独立分发。它可在支持的 AI 客户端生成可编辑 PPT，并输出可在工作台中继续核对和编辑的 `.lesson.zip`。

## 安装

下载 `LessonDesk-0.18.0-Setup.exe`。同一发布页提供 `SHA256SUMS.txt`。正式版和测试版使用各自的数据目录。

## macOS 试用包

macOS 试用包基于同一份 0.18.0 正式版源码。打开 [macOS preview 构建记录](https://github.com/zazedwhwhy/lesson-desk/actions/workflows/macos.yml)，从成功运行的 **Artifacts** 下载对应压缩包。Apple 芯片选 `LessonDesk-macOS-arm64`，Intel 芯片选 `LessonDesk-macOS-x64`。两个架构的自动测试均使用 macOS 15。

1. 解压下载的文件。进入解压后的目录运行 `shasum -a 256 -c SHA256SUMS.txt`，确认 DMG 校验通过。
2. 打开 DMG，把「讲题工作台」拖到「应用程序」，再从 Finder 启动。
3. 试用包使用临时签名，尚未经过 Apple 公证。首次启动可能被系统拦截。核对下载来源后，按 [Apple 的说明](https://support.apple.com/zh-cn/102445)查看「隐私与安全性」中是否提供「仍要打开」。

如果手边没有 Mac，可以先看 Actions 的截图、测试报告和日志，再请有 Mac 的同事试装，或用 Windows 连到一台有桌面会话的远程 Mac。两种架构尽量各测一次。

| 人工测试 | 通过条件 |
| --- | --- |
| Finder 安装和启动 | 能从「应用程序」冷启动，退出后能再次打开。记录芯片、macOS 版本、首次提示和失败原因。 |
| 文件与跨机数据 | 用系统对话框选择带中文文件名的 PDF 和 DOCX，并另存 PPT 与课件包。从 Windows 导出 `.lesson.zip` 后在 Mac 导入，核对题面、答案及素材。API Key 需要在 Mac 上重新填写。 |
| AI 与系统集成 | 用测试材料完成一次扫描识别与讲义生成，核对通知及点击返回。退出重开后检查钥匙串权限与连接是否可继续使用。 |
| 课堂与 Office | 核对三种课堂版式、全屏与键盘翻页。用 Mac 版 PowerPoint 打开导出的 PPT，检查文字可编辑，且中文字体、化学公式和题图显示正常。 |

自动测试使用合成材料，检查安装映像、应用启动、PDF 和 DOCX 导入、PDF 渲染、放映、PPT 导出及重启持久化。Finder 启动、系统对话框、钥匙串、通知、真实 AI 调用和 PowerPoint 排版由人工验收。
