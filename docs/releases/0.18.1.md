# 讲题工作台 0.18.1 · macOS 移植版

macOS 版与同一提交的 Windows 构建共用英语、语文、化学的备课、教学讲义、课堂放映和可编辑 PPT 导出流程。本版同步纸色标题栏、统一的圆角和内容分区，以及随内容和窗口高度伸展的对开讲义。macOS 窗口保留系统的关闭、最小化与缩放控件。

## 下载与安装

- Apple 芯片选 `LessonDesk-0.18.1-macOS-arm64.dmg`，Intel 芯片选 `LessonDesk-0.18.1-macOS-x64.dmg`。
- 从发布页下载 `SHA256SUMS.txt` 核对文件。打开 DMG，将「讲题工作台」拖到「应用程序」。
- 在另一台电脑上继续备课时，从原应用导出 `.lesson.zip` 后在新电脑导入，在「连接设置」重新填写服务凭据。

试用包使用临时签名，尚未经过 Apple 公证。首次启动若被拦截，核对下载来源和校验值后可参阅 [Apple 首次打开说明](https://support.apple.com/zh-cn/102445)。

## 验证范围

打包应用验收覆盖启动、原生标题栏预留区域、对开讲义、独立滚动、放映翻页与全屏、PDF 和 Word 导入、PDF 原页渲染、课件包导入导出、可编辑 PPT 导出和数据重启保留。验证使用合成课件和模拟文件选择，Finder 首次安装、钥匙串与通知、真实 AI 服务和 Microsoft PowerPoint 排版需独立实机验收。
