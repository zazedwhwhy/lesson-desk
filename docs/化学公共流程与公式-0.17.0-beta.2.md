# 0.17.0-beta.2 化学公共流程与公式

需求：化学公共页面和操作方式与英语及已改好的语文一致，仅讲评模块按学科区分。保留原题保真、OCR核对和历史版本修复。加入离线 LaTeX 和化学式显示，只使用合成材料、模拟响应和离线测试，验证后发布新测试版并注明改动。

实现：复用 WorkspaceHeader、PreparationPage、SourceMaterials、ReviewBatch、LessonSetupView、PptTemplatePicker、PresentationView 和导出/备份组件。按题选择生成五种化学模块，保留配图、图示说明、视觉模式、教师修订及版本核对。继续生成使用保存的精确任务，条件变更会阻断。编排默认使用最新有效已确认讲义。

保留原视觉：纸面底色、Literata/文楷、现有按钮及导航文案。工作页面为 Operate，授课阅读为 Read。没有重新设计配色和独立化学导入/导出流程。

验证接缝：核对/拆合题/历史及版本选择、真实生成调度的模拟调用、公式解析/分页/输出文件、独立profile桌面交互与打包内容一致性。禁止真实AI API请求。
