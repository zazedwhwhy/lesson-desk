# 讲题工作台 0.17.0

2026-11-16 · Windows x64 · 本地交付，未推送或发布 GitHub。

## 这次修好了什么

- **连接管理**：返回移到页首；常用 API 可命名、查看、切换、删除；已保存密钥可按需显示和隐藏。编辑草稿与当前连接分离，未保存离开会提醒。更换服务商或地址必须填写新密钥，避免误发旧凭据。
- **操作路径**：修复重复进入设置造成的返回循环；提示词、授课编排统一顶部返回。错题条目离开前提醒未保存内容，提示词保存期间锁定编辑。
- **化学编辑数据丢失**：快速从题干移到答案时，字段保存曾锁住整组输入并清空下一字段。现保留输入草稿，按顺序保存最新编辑，保存失败会阻断依赖它的后续快照。桌面保存去掉重复的前端修订处理，由后端对实际保存版本校验。
- **提示词拼装**：修复替换内置/自定义模板时丢掉题号范围、数量和修正反馈的缺陷；全部 34 个注册模板均有回归覆盖。
- **各科生成**：语文的参考答案规则只约束原题讲评，不再压制语言分析和写作立意；单篇不要求做多篇比较，阅读简答不应标作文；无图文本不因默认图片核对值误报。英语加强词汇例句与译文对应、辨析边界、练习唯一答案、语法变体和续写衔接；明确数字范围的写作词数先本地检查；新练习统一换行，并去掉与options逐字一致的尾部重复选项表。化学演练改用固定题目/答案/解析字段，再由软件排版，并要求新题提供排除干扰的条件。
- **错误处理**：未知程序异常不再当成普通内容失败继续派发或再次付费请求；缺少原题题号时明确报告，不再拿整卷充当已定位来源。取消、服务故障、损坏配置、保存失败和引用校验仍保留。
- **速度与代码**：英语长卷校对最多三段并行，乱序响应按原段合并；服务拒绝后递归拆分也保留“只校对本段”的范围。连接页和连接存储从主文件拆出，模板目录复用；优先本地校验以减少无效复核请求。测试保留行为断言，修正了假装验证乱序的等延迟测试；QA工具和真实调用账本不进入应用包。

## 数据与安装

安装器：`release/0.17.0/LessonDesk-0.17.0-Setup.exe`。正式版安装名称为“讲题工作台”。首次启动将工作数据复制到 `%APPDATA%/lesson-desk-stable`，优先来源为 `lesson-desk-beta`，其次为旧 `lesson-desk`；原目录保留，正式目录已存在时不覆盖。复制包含同源的 Windows 加密上下文 Local State、连接、提示词、课件、错题本与PPT模板，不复制缓存。旧版和正式版以后各自保存，不双向同步。

安装前关闭正在使用的旧版，使最后的课件和加密上下文完成写入。此次没有在用户真实数据上执行覆盖安装或卸载。程序未签名；正式版编号代表这次打包版本，不代表AI候选已经获得教师确认。

覆盖三科整理和校对、英语解析/翻译/四教学模块、语文六模块、化学五模块及七种独立练习。初轮语文整理误用了已完成fixture，被复用而未请求AI；已改为清空题组后重新实测，不将那次计为真实整理通过。最初两次七题型合批被质量复核拒绝，后来按实际逐题任务路径分别复测；失败记录全部保留。
