# 化学测试版设计与实施

目标：在讲题工作台增加中学化学图文试卷备课、分模块讲评、课堂展示和 PPT 输出，发布 0.17.0-beta.1 测试版。

调研依据见《化学学科调研-2026-11-12.md》。已核对 PDF.js 原页渲染与 Mammoth 图片/文本提取边界。原图必须保留，不能把 OCR 文字当作完整题面。

## 设计决策

采用独立化学数据和工作台，复用文件导入、AI 请求、存储和 PPT 分页；比硬套英语题型更能表达实验、知识条件，也比复制语文流程更容易维护。用户授权直接设计实施，以下实现选择由开发者确定。

- 题目支持题型、题干、选项、参考答案、来源、页码、图示、多图及核对状态。支持 PDF/Word、粘贴与手动录题、PNG/JPG 图片。PDF 原页和 Word 内嵌图片可绑定到具体题目。
- 图文并列：题图保持比例、可放大，题干和讲评独立阅读。扫描卷允许先看原页手动录入，也可沿用扫描识别。
- AI 图像输入显式选择：视觉模式发送关联图片，接口拒绝就报错；文字模式要求教师填写并核对图示说明。无图片时直接用题面。均不猜测缺失装置连接、数据或药品。
- 五个模块：逐题讲评（依据、推导与答案冲突）、知识梳理（条件、边界、联系与反例）、题型方法（判型、步骤、检查）、实验剖析（目的、原理、操作、现象、证据、误差、改进）、考点演练（新题、答案和解析分开）。不适用模块可不选。
- 勾选题目和模块，一次启动；每题每模块独立状态/错误/尝试次数/历史版本，服务错误停止后续调用，内容错误记录后继续；取消、重启后可重试未完成项。无模板回填或伪造成功。
- 教师可编辑并保存新讲义版本，核对后纳入输出；题面、答案、图片或读取方式变化会撤销题面核对，旧讲义失效但保留。
- 编排按题目与模块选择；当前勾选的缺失/过期/未确认内容阻断输出，允许取消勾选未完成项。放映和 PPT 共用分页；题图单独一页，演练题与答案分开。
- 备份课件包包含图片与历史；兼容原英语/语文存档。化学错题收录沿用错题本。

## 界面结构

延续现有字号、按钮和色彩，化学原图区作为视觉中心，不重做整个软件。

```text
化学 · 测试版             材料与题目 / 生成讲评 / 编排课件
试卷来源与页码 | 题目列表 | 当前题目、原图、核对
                         模块多选 → 开始生成
                         知识/方法/实验结果及版本
                         编排预览 → 放映 / PPT
```
