# 讲题工作台 0.17.1

2026-11-16 · Windows x64 · 本地正式版，未推送、未发布 GitHub。

## 化学题图

整理化学 PDF / Word 试卷时，AI 自动识别工艺流程、实验装置、统计曲线、表格和结构示意，给出范围与题目归属。程序保存原图，不重画装置或改写坐标数据；公式继续使用离线 LaTeX/mhchem。

题图直接显示在题面核对、教案讲解、只看讲解模式、放映和 PPT 中。跨页续图可以属于同一题，共享图可以供多题使用。自动图随整题核对，不新增逐图确认步骤。归属不明的原图保留在“题图待关联”区；手工附图与说明方式仍可使用。教师移除自动图后，补齐遗漏题目不会把它重新挂回来。

识图按页或 Word 嵌图保存，已完成单元可复用。Word 根据图片前后文字判断归属，透明图片发送前补白底；PDF 渲染最大边限制为 3200 像素。坐标越界或不可读时明确报错，仅坐标内容错误允许一次修正；凭据、网络或保存错误停止本次识图，不生成替代图。

Windows 上连续复现的备份导入 rename EPERM 增加了有界原子重试：仅对文件占用/权限错误最多等待 1.55 秒，始终执行相同重命名，不删除目标、不复制替代，持续失败仍抛出原异常。项目保存共用该操作。

另修复 OCR 核对保存时整理按钮仍可点击的交互空隙，并明确 Word 缺少来源页码时返回空页码，避免猜页码造成重复请求。自动图已关联时去掉软件插入的“补充图片文字”占位提示。
