# 0.17.0 正式版修复与验收计划

目标：在现有 Electron/React/TypeScript 程序上完整回归，修复已确认缺陷，保留纸面教案风格，交付本地正式版。用户已授权修复、优化与打包，禁止推送 GitHub；本机 OpenAI 实测预算上限 USD 5。

基线：6b92b9a，0.17.0-beta.11；原有未跟踪 designs/ 保留。

## 设计与取舍

采用现有产品上的渐进改造：连接设置独立组件、页首返回、连接列表、默认遮蔽且按需查看密钥、草稿与已生效设置分离、离开提示。系统风格替换与玻璃重设计会改变用户认可的纸面教案，因此不采用。保留 #eeeae0 / #faf7ef / #302c26 / #a64e36 / #ded8cb，标题文楷，表单系统字体，左对齐；连接与生成偏好分组，不增加装饰动画。

## 实施顺序与验收边界

- [x] 基线：全量 Vitest、当前桌面真实界面路径；独立回退审计输出语义清单。
- [x] 连接设置：新增 desktop/settings-store.ts 原子存储与旧单连接迁移；core/model.ts 增加连接标识；ui/ConnectionSettings.tsx 管理连接、按需查看密钥、草稿与返回；main/preload 加受限 IPC。公共存储接口测试覆盖迁移、密钥隔离、修改地址、损坏文件与删除；真实界面检查保存和返回。
- [x] 提示词：修复 PromptBook.compose 丢失动态范围/数量/重试约束；对全部注册模板测试默认与自定义组合保真。评估各任务的材料体积与多余往返，保留教学质量校验。
- [x] 可靠性：按审计的真实因果链修复，保留取消、安全闭包与必要校验。为每个数据丢失或假状态缺陷增加行为回归，避免断言源码字符串。
- [x] UI：三学科主流程、提示词返回、错误/空态、任务反馈、导出取消、窄窗口；由 computer_use 单独操作界面。
- [x] 真实 AI：只用现有 OpenAI/gpt-6-luna/官方地址；密钥仅在内存解密；逐请求预留预算、记录 usage，失败保留预留；使用人工可核对的小型三学科材料，不修改用户课件。
- [x] 正式版：核对测试版数据延续与正式版身份，更新 0.17.0、发布说明、回退审计、实际验证矩阵；打包安装器并检查包内容/散列/启动与导出。
- 提交规则：仅提交本次变更，提交后再验证；不 push、不创建远程发布。最终提交和检查记录写入本地交付记录。

## 重点风险

端点修改不能继承旧密钥；未保存配置不能影响生成；提示词自定义不能删除动态材料与校验反馈；重试不能隐藏磁盘/凭据错误；正式版不能让测试版材料看似丢失。真实模型质量与模拟协议验证分开记录，速度结论必须注明样本。
