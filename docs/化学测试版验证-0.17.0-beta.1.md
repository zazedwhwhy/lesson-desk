验证日期：2026-11-12。版本：0.17.0-beta.1。测试数据均为自编样例，界面使用隔离数据目录。

## 已完成

- `npm test`：本地提交 `c24e152` 后重新执行，68 个测试文件、421 项通过。
- `npm run build`：TypeScript、Vite 和 Electron 主进程构建成功。保留既有字体与打包结构；Vite 有大块体积提示，不是构建失败。
- `npm run check:public`：181 个已跟踪文件通过，未将原有 `designs/`、用户课件、设置、凭据或依赖目录加入提交。
- 化学核心：题面/图片变更使历史讲义失效；图示未确认与缺少文字说明阻断；演练题答分离；教师修订也必须满足演练三块结构。
- 生成流程：模拟模型响应，覆盖单项内容失败、未知异常/服务错误阻断、保存失败中止、取消丢弃晚到结果、重试跳过已完成项，以及视觉和文字模式请求差异。
- 文件集成：真实 DOCX 数字上下标读取、图片与教师版本课件包往返、任务中断恢复、实际 PPTX 页序/媒体/Unicode 检查。
- Electron 源码与打包程序交互：新建化学、录题保存、PNG 导入/放大、图示修改后核对失效与重新确认、课堂编排/放映、重启后内容保留。
- 打包程序模拟生成：拦截主进程 fetch，选择三个模块，观测三个模拟请求和独立状态；核对 AI 版本、编辑另存教师版本、核对教师版本、选入课件。
- 打包程序实际 PPT 输出：自编样例 5 页，检查第一页题面、第三页教师练习和媒体资源。1000×650 窗口未发现页面横向溢出。
- 最终包补验：英语示例打开并显示正文讲评；复选框横向对齐；自编 PDF 经界面导入、查看第一页并附到当前化学题（该临时附图未保存）。
- 最终包一致性：6 个构建入口/脚本/样式文件与 app.asar 内容逐字一致，安装包大小 144,650,500 字节，SHA256 记录在发布目录。
- 独立静态复核：完成回退专项审计；发现并修复教师修订演练可绕过结构校验的问题，修复后未发现化学新增链路剩余高风险项。

npm run build
node scripts/chemistry-ui-qa.mjs
# 验收打包程序时设置 CHEM_APP 为本机 win-unpacked 中的可执行文件路径
node scripts/verify-selected-package.mjs

界面截图、详细交互报告、PPT 样例和包校验记录保存在本机 `test-results/`，不包含在产品安装包中。安装包、SHA256 清单与发布说明单独放在 `release/0.17.0-beta.1/`。

## 明确未验证

没有使用真实付费 API 生成完整化学卷，没有验收任何服务商真实视觉模型的识图准确性。桌面交互覆盖 PNG 与自编 PDF 原页；未用真实扫描化学卷验收 OCR 质量。未执行安装器安装流程、未用 PowerPoint 打开导出文件、未迁移用户真实历史数据。测试版使用独立数据目录，旧课件包兼容由本地集成测试验证。
