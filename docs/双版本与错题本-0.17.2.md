# 0.17.2 正式版与 0.17.2-beta.1

2026-11-16 · Windows x64 · 本地交付，不推送 GitHub。

## 选择哪个版本

| | 0.17.2 正式版 | 0.17.2-beta.1 测试版 |
| --- | --- | --- |
| 应用名称 | 讲题工作台 | 讲题工作台 Beta |
| 错题本 | 移除入口、收录栏和后台接口 | 保留修复后的功能，标注 Beta |
| 试卷、教案、化学题图、PPT | 保留 | 保留 |
| 数据目录 | `%APPDATA%/lesson-desk-stable` | `%APPDATA%/lesson-desk-notebook-beta` |
| 安装包 | `release/0.17.2/LessonDesk-0.17.2-Setup.exe` | `release/0.17.2-beta.1/LessonDesk-0.17.2-beta.1-Setup.exe` |

两版安装标识不同，可并存。正式版不删除已有 `notebook.json`。Beta 的新数据目录首次创建时，优先复制正式版的数据，其次是旧测试版数据；原目录保留。已有 Beta 目录不覆盖，两版后续修改不自动同步。跨版继续编辑课件可用课件包导出和导入。

## 修复内容

- 截图中的底部收录栏和通用任务提示同为固定定位，后者的文字、取消按钮被遮挡。Beta 收录栏改为页首正常文档流，不占用底部任务提示区域。正式版完全移除该栏。
- 收录工具只在课件列表、整理材料和教案页面出现；设置、提示词、授课编排、放映不显示。
- 错题本改为模态对话框，避免操作落到背后的课件。顶栏关闭和 Escape 都保护未保存编辑，保存期间不能关闭。
- 化学原文栏选中文本会记录题目来源；题目、材料、讲义版本位于不同祖先节点时分别定位。
- 化学与语文讲义片段检查对应模块的新版本，不把实验或其他模块误当逐题讲评。原讲义被删除时明确报错，保留收录快照。
- 整段收录不混入界面段号、按钮和输入控件；来源比较统一空白，避免仅换行不同就误报失去来源。
- 同一页面内修改和保存课件不再清空错题本选题；切换页面清除选区，避免收录隐藏页面文字。
- 化学错题列表与参考讲解使用现有公式渲染；错题存储沿用有界原子重命名，持续保存错误仍明确报告。

## 验证与构建

147 个测试文件、915 项测试通过，包括正式版拒绝错题本接口、Beta 开放接口、来源定位、讲义版本选择、复制数据不回写、学生版输出隔离及三科回归。TypeScript 与两版生产构建通过。

界面验收使用独立配置和合成课件。1000×720 的慢 OCR 场景复现了旧版遮挡，Beta 修复后取消按钮可见且能取消。三科整题/片段收录、编辑保存、关闭提醒、搜索、归档恢复、复讲、教师/学生 PPT 及学生 PDF 输出均有独立验证。未调用真实 AI，未覆盖安装或修改用户真实数据。

构建入口分别为 `npm run package` 与 `npm run package:beta`；打包明确关闭发布。正式版的错题本代码在构建阶段剔除；Beta 使用独立的 `dist-beta`、`dist-desktop-beta`，防止两版混装。`node scripts/verify-release.mjs <版本号>` 检查包内版本、构建文件一致性、错题本代码启用状态及个人数据排除。

本地界面证据位于 `test-results/release-0.17.2/`，包内容与哈希记录分别位于两版的 `test-results/release-<版本>/package/`。安装包保留未签名状态；本轮验证的是解包程序及实际输出文件，没有执行安装/卸载或原生 PowerPoint 播放。
