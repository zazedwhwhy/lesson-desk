# 备课界面优化 · 0.16.1

本版调整英语「整理材料」与语文「整理与核对」页面，用连续分区和步骤链接组织材料核对、教学内容生成、导出与备份。讲课、阅读、放映、授课编排、错题本和 PPT 模板布局沿用原有设计。

## 选择生成范围

英语先在题目清单中核对题面与答案，再勾选需要的模块，一次开始生成。页面显示当前勾选范围内已核对、待核对及已排除的题目数量；未勾选题目时，范围为整卷已核对且未排除的题目。只安排适用题型的内容。

语文可以选择材料组、题目及多个模块。逐题讲评与考点演练按所选题目生成，其余模块按适用材料组生成。不适用模块不能勾选；所选题面尚未核对时，需要先核对或取消选择。清空题目选择不会自动改成全卷生成。没有材料组时，生成区说明准备步骤并禁用开始按钮。

生成区显示所用服务与模型，并提供连接设置入口。相应材料会发送给已配置的服务；浏览器预览不能调用桌面生成功能。

## 查看结果与继续任务

每项内容独立保存。页面显示真实的已保存数量、未执行项、失败项和具体原因；已保存不等于教师已核对。英语区分取消、服务暂停与中断状态；语文取消时显示请求已发送，最终结果以逐项状态为准。旧任务没有记录取消原因时，不推测其结束原因。

新生成保留旧版本与教师修订。继续未完成项沿用上次任务范围，跳过已保存内容，不跟随当前题目勾选悄悄改变范围。材料、答案或核对状态变化后，需要重新选择生成。服务暂停时应先处理提示的问题，再继续任务。

语文无参考答案时，AI 作答仍为待核实建议；生成后请进入备课讲义核实、必要时修订并确认，再加入授课编排。

## 导出与备份

- **编排并导出 PPT**：进入原有编排页，由教师选择篇目、题目和模块，选择模板后输出可编辑 PPT。放映和 PPT 继续使用相同的内容顺序与分页规则。
- **导出备份课件包**：保存材料、生成内容及修改记录，可重新导入工作台继续备课。课件包不是 PPT，也不含模型服务的 API 凭据。

本版不迁移课件数据结构。已有材料、历史版本、教师修订和独立模块状态继续保留。
