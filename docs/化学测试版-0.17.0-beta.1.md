# 化学测试版 0.17.0-beta.1

新增中学化学图文试卷工作台。安装程序名称为“讲题工作台测试版”，使用独立数据目录 `lesson-desk-beta`，可与正式版并行使用。原有课件可在正式版导出课件包，再导入测试版；API 设置需在测试版单独填写。

## 第一次使用

1. 新建课件，学科选“化学（测试版）”。
2. 导入 PDF / Word 试卷和答案，或新增题目手动录入。AI 整理需要自己的 API 配置；纯手动备课、图片展示和导出无需 API。
3. 对照原页核对题干、选项、上下标和参考答案。PDF 可按页查看并附到当前题，Word 内嵌图可逐图附入，也可上传 PNG/JPG。
4. 保存题目后确认图示与题面。文字模式须填写每张图的说明（连接、试剂、刻度、条件）；视觉模式会把关联原图发给当前模型，模型必须支持图像输入。题面或图示发生实质改动后，会自动清除核对标记，需重新核对。
5. 进入“生成讲评”，多选题目与模块，点击一次“开始生成”。各项独立保存；失败可重试未完成项，取消保留已经保存的内容。
6. 核对讲义。可编辑并另存教师版本，旧版本始终保留。待核实结果须修正后声明问题已解决，再核对；过期讲义不能直接重新确认。
7. 进入“编排课件”，按题目、模块与版本选择，更新预览，再放映或导出 PPT。允许不选择未完成模块，所选不可用模块会阻断本次输出。演练与答案分开分页。

## 五个模块

| 模块 | 讲评重点 |
| --- | --- |
| 逐题讲评 | 已知、条件、知识依据、推导、答案、选项与易错原因 |
| 知识梳理 | 成立条件、适用范围、反例、本题联系与扩展 |
| 题型方法 | 判型线索、可复用步骤、代入过程、单位与守恒检查 |
| 实验剖析 | 目的、反应原理、装置作用、操作顺序、现象与证据、误差及改进 |
| 考点演练 | AI 新编变式题、独立答案、解析与迁移 |

每题可选初中或高中，提示词约束相应知识边界。所有化学提示词可在模型设置中编辑，动态题面与输出格式由程序保留。

## 图片与公式

原图按比例展示，点击可放大、滚动查看。课堂和 PPT 将题图独立成页，不裁切装置。自动识别不能保证图示、上下标、箭头或反应条件正确，需对照原图核对。

化学式使用 Unicode 上下标，例如 `SO₄²⁻`、`Ca(OH)₂`、`CO₂↑`，保持文字可编辑。Word 的数字上下标转换为对应 Unicode，同时原预览保留 `<sub>` / `<sup>`。本版不是 LaTeX/mhchem 排版引擎：复杂结构式、箭头上方反应条件和多层式子请保留原图，不声称自动重建。

测试版化学 PPT 当前采用纸面教案样式。英语与语文保留现有模板选择。课件包保留化学题图、教师版本、整理历史和任务状态；不会包含 API Key。整题及讲评片段可收录错题本，化学考点演练可关联收录。

## 错误处理

无 API Key、网络/服务错误、未知内部异常会停止后续生成。仅明确的模型内容校验失败允许继续其他项。保存失败直接中断，不伪装成 AI 内容失败，不写入通用讲解作为替代。待核实输出保留供教师诊断，但不计为成功，也不能直接导出。

## 验证边界

自动化测试覆盖数据、模拟模型请求、失败/取消/恢复、Word 上下标、课件包图片往返与实际 PPTX XML/媒体。桌面交互验证记录另附。模拟接口成功不代表任何真实账号、视觉模型或完整化学卷已通过质量验收；本次不使用用户付费凭据进行试卷生成。
