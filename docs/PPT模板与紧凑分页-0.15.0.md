# PPT 模板与紧凑分页 · 0.15.0

安装包：`release/ppt-templates-0.15.0/讲题工作台 Setup 0.15.0.exe`。

## 使用

1. 英语课件点击“输出课件”，语文课件点击“编排授课 / PPT”。
2. 在“PPT 模板”中选择纸面教案、清爽蓝白或墨绿课堂，也可点击“上传 PPT 模板”导入自己的 `.pptx` / `.potx`。
3. 按篇目、题目和模块勾选内容，检查预计页数，然后点击“输出可编辑 PPT”。

上传过的模板保存在当前 Windows 用户的应用模板库中，后续可从“我的模板”选择，不需要再次上传。取消上传或上传失败时保留原来的有效选择，错误会显示在模板区。切换模板会按它的正文空间重新计算页数，放映和导出使用同一顺序及分页。

## 分页规则

同一份讲义的短内容及其依据尽量合页；长文字按剩余空间拆分，过短的续页会重新平衡。同一练习、题面与答案保留讲授边界，防止还没作答就看到答案。短题面或原图可能单独成页，不通过塞入无关内容、丢字或缩小正文来填满。

## 自定义模板范围

支持横向 PowerPoint 模板，单文件 25 MB 内；模板的宽度为 6–24 英寸，高度为 4–15 英寸，含常见 16:9 和 4:3。使用可识别的正文占位框；没有该占位框时使用留边的统一正文区域。标题与正文重叠或超出页面时会提示调整模板。

软件读取主题字体、颜色和正文区域，导出时复制所选版式、母版及背景图片等资源。自动优先选有正文占位的版式，同类版式中优先选择模板实际使用的版式。模板中的示例正文不进入课件。普通演示文件直接画在某张幻灯片上的独立装饰不会自动变成母版装饰；建议将需复用的背景、校徽等放入 PowerPoint 的“视图 → 幻灯片母版”。

应用内为主题和正文排版预览，复杂母版装饰以导出的 PPT 为准。损坏文件、缺资源、外部链接、宏、嵌入对象及无法识别的母版对象会阻止导入，不会静默换回默认模板。上传前在 PowerPoint 中将需要的图片嵌入模板，可避免外部图片关系导致导入失败。
