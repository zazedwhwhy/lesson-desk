# 语文整卷功能 0.14.0

新建课件时选择“语文”。导入 PDF / DOCX 或粘贴试卷后，点击“整理整张试卷”，逐组核对题面、原文与参考答案。扫描 PDF 先识别扫描页。图表可附入 PDF 原页或 PNG/JPG，并单独确认图像；Word 原图可从原材料预览查看。

语文按信息类阅读、文学类阅读、文言文、诗歌、默写、语言文字运用、写作组织。支持多篇材料、跨组关联、子问题号及教师补充。完整性检查可定位未核对、重复题号、材料缺失等问题；AI 对照校对保留覆盖范围和限制，原页图片仍需教师核对。

勾选材料组、题目及教学模块后，一次开始生成。逐题讲评、文本脉络、语言品读、文言译注、写作指导和考点演练按适用范围生成。新编演练先提炼考点，再隔离原题生成新材料，并独立复核。失败不覆盖好版本，可继续未完成项；取消后保留已保存内容。系统通知与页面进度显示生成结果。

备课讲义中可查看原文依据、展开参考作答、另存教师修订版并确认。缺少参考答案的 AI 作答保持待核实；材料、题目或答案变化后旧讲义不可直接加入课件。整理历史和讲义历史保留。

点击“编排授课 / PPT”，选择原文和已确认讲义，再放映或导出。两者共用页序，题面、解析、证据、参考作答及演练均可输出，长内容分页。方向键、翻页键与空格翻页，Esc 返回编排。

- 使用正式打包后的桌面软件与隔离的本地测试课件验证新建语文项目、核对、查看讲义、课件选择、放映和实际 PPT 输出。截图及验证 PPT 在 test-results；测试内容是明确的验证样例，未冒充真实 AI 生成。
- Impeccable 机械检查未报告问题；纸面风格、中文字体与 1366×768 / 1920×1080 投屏检查保留。
- 真实 API 对历年高考整卷的识别完整度与教学质量尚未联测；不能用模拟接口测试代替此项。导出的 PPT 已核对内部文字与页数，未在 Microsoft PowerPoint 中人工逐页检查。
