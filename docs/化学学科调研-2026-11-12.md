# 化学学科调研：讲评内容、图文证据与化学式

调研日期：2026-11-12。范围：中国中学化学讲评，以及 Windows Electron 讲题工作台的可实施设计依据。本次为资料研究，未修改业务代码、未调用付费模型、未进行真实试卷端到端验证。下文区分来源事实与产品建议；建议不等于已实现功能。

## 1. 结论

建议将化学设为独立学科，设置“逐题讲评、知识梳理、题型方法、实验剖析、考点演练”五个可独立选择和生成的模块。重点是讲清条件与证据链，而不是把语文/英语模块改名。

- 知识点必须包含适用条件、推理过程、边界与反例；迁移题要明确改变了哪个条件。
- 实验内容按“目的—原理—装置与操作—现象—证据与结论—误差—改进”组织。题目给出的现象、模型预期现象、教师补充必须分开。
- 原始 PDF 页、题图和图表是证据。OCR 文本是可校对的辅助结果，不可替代装置图、流程图、曲线和结构式。
- 题图应支持独立缩放、页码追溯及人工调整关联。图片说明由教师确认；模型没有收到图片时，不得生成“图中可见”的断言。
- 视觉调用设置显式开关。不支持图片、图片读取失败或能力未知时，应报告具体问题并阻断依赖图像的生成，不自动伪装成已经读图的文本分析。
- 屏幕讲解与 PPT 应复用相同模块顺序和内容模型，化学式与原图需要分别验证，不能仅凭页面文字正常就宣布 PPT 可用。

以上是根据课标方向、文档工具能力和本项目讲评用途提出的产品建议，并非课标规定了软件模块。

## 2. 教育依据与适用边界

### 2.1 初中化学

教育部《义务教育化学课程标准（2022年版）》重视事实与逻辑、宏观/微观/符号之间的联系，以及实验设计、现象解释和证据推理；其学生必做实验包括气体制取、常见物质性质、溶液配制等。工作台应将实验判断建立在材料和观测上，避免只提供记忆口诀。[教育部课标 PDF](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020230605524875861384.pdf)

初中模式建议限制知识深度：不主动引入高中平衡常数、复杂电化学或结构理论解释；如果题目自带新信息，可以基于题给材料推理，并标注“题给信息”。初中独立化学与地方综合科学的课程组织可能不同，应允许教师选择学段和课程形态，不能用一个“初中”标签推断全国统一章节安排。这属于产品范围建议，具体教材映射仍需教师核对。

### 2.2 高中化学

高中课标的五个素养维度包含宏观与微观、变化与平衡、证据与模型、探究与创新及社会责任。教育部的相关说明强调探究、实践与项目学习，支持将讲评重点从孤立答案扩展到推理依据和方法。[教育部关于化学教学装备与核心素养的说明](https://hudong.moe.gov.cn/jyb_xwfb/moe_2082/zl_2019n/2019_zl39/201905/t20190531_383953.html)

高中课标版本可追溯到教育部发布的《普通高中课程方案和语文等学科课程标准（2017年版2020年修订）》，人教社提供分科入口。这里确认了发布版本和入口，不据此声称已核实所有地区截至本日的最新考试范围。[教育部发布通知](https://www.moe.gov.cn/srcsite/A26/s8001/202006/t20200603_462199.html)、[人教社课标入口](https://www.pep.com.cn/xw/zt/rjwy/gzkb2020/)

高中模式建议区分必修、选择性必修及题给拓展信息。知识迁移优先解释“同一规律在不同条件下怎样应用”，避免把高考题型当作互不相通的固定模板。

### 2.3 实验不能只剩答案

教育部发布《中小学实验教学基本目录（2023年版）》的说明指出，目录以现行课标为依据，覆盖初高中化学等学科的基础实验与实践活动。这支持保留操作、观测、解释和评价环节；它不意味着一个讲评软件能够替代真实实验教学。[教育部实验目录发布说明](https://fx.xwapp.moe.gov.cn/article/202311/65604ad681c0d4753f445696.html)

## 3. 五模块的可落实内容协议（产品建议）

| 模块 | 应输出的内容 | 需要阻止的输出 |
| --- | --- | --- |
| 逐题讲评 | 题号及小问、题干关键条件、已知与所求、答案及证据、步骤、干扰项、易错原因 | 缺图时编造装置连接；没有学生原答时声称学生犯了某个错误 |
| 知识梳理 | 概念/规律、成立条件、适用对象、推导/证据、边界或反例、与本题的关联 | 只列名词；将特殊条件结论推广为普遍规律 |
| 题型方法 | 识别线索、前提、步骤、检查点、何时失效、同法迁移 | 见“平衡”就套同一判据；脱离条件列万能口诀 |
| 实验剖析 | 目的、原理、部件功能、操作顺序及原因、实际现象、推理、控制变量、误差、改进 | 把“生成某物质”当作肉眼可见现象；默认所有装置都有洗气/干燥等环节 |
| 考点演练 | 与知识/方法绑定的变式题、改变的条件、完整答案与推理、适用学段 | 未给必要条件的题；声称 AI 自编题是官方真题；一次答对即判定掌握 |

建议把题型标签用作检索和提示，不用它替代推理。可覆盖物质分类与转化、方程式、定量关系、实验探究、图表分析，以及高中结构、有机、反应原理、流程题等；具体启用由学段和实际题目决定。

### 3.1 条件与迁移的最小结构

建议每条重要知识记录以下字段：

1. 规则：具体描述，不只写“平衡移动”“守恒”。
2. 条件：温度、压强、浓度、物态、介质、装置开闭等；题目没有给出且影响答案时标“缺条件/待核实”。
3. 证据：题干语句、表格数据、图片标记或教师给定依据。
4. 推理：条件如何导向结论，不能只展示最终方程式。
5. 边界：什么改变会使当前方法失效。
6. 迁移：变式只改变一项关键条件，并解释答案变化或不变的原因。

例如，某系统颜色、某物质量或某测量量“不变”是否能证明平衡，必须先检查它是否随反应进程变化、题设条件是否固定。该示例是讲评设计建议，不是针对任何未提供试题的答案。

### 3.2 实验误差必须能追到测量关系

建议采用“操作偏差→影响哪一项测量/物质量→代入题目实际计算关系→结果偏高/偏低/不能确定”的链条。没有测量定义或计算关系时，不强行给出误差方向。图中部件应以原标签关联，例如 A/B/C；不凭经验重命名成题目未出现的仪器。

“实验改进”应指出它解决哪一个问题以及引入的代价。没有相关问题的气密性检查、尾气处理、安全说明不应机械塞进每一道题；涉及真实实验操作的建议仍需教师按实验室条件审核。

## 4. 图文输入与证据保留

### 4.1 PDF：原页渲染与文本提取是两条链路

PDF.js 官方示例展示了逐页读取、viewport 变换和 canvas 渲染；官方 API 另提供文本提取接口。这些是不同接口，提取出文字不能证明图形信息已保存。[PDF.js 示例](https://mozilla.github.io/pdf.js/examples/)、[PDF.js API](https://mozilla.github.io/pdf.js/api/draft/module-pdfjsLib-PDFPageProxy.html)

建议：

- 保留原文件和每页的身份；为每题建立 `sourceId + pageIndex + cropRect` 关联，跨页题允许多个片段。界面显示的页码从 1 开始，存储索引规则明确。
- 裁剪图必须来自实际原页，保留原比例；题干图、选项图、表格、实验流程可分别关联，教师可重新选区或换页。
- 页面旋转/缩放/裁剪框都需要同一坐标转换，不把屏幕像素直接当 PDF 坐标。PPT 导出保持比例，不截掉坐标轴、图例或仪器接口。
- 题目文本与原图并存；OCR 修订只改派生文本，不写回原文件。
- 如果页渲染失败，应保留原文件并报告失败页，不以一个空白“已导入”页继续生成。

### 4.2 DOCX：不要将纯文本导入标为完整图文导入

Mammoth 的 `extractRawText` 忽略格式；`convertToHtml` 支持图像、上下标等，但不保证复杂排版完整还原。文本框的内容位置也可能变化。官方还说明它不负责清洗不可信 HTML。[Mammoth 原作者文档](https://github.com/mwilliamson/mammoth.js)

建议：保留原 DOCX；解析结果保留块顺序、图像和转换告警。无法确认题图归属时交给教师选择，不按时间戳或“最近一张图”强行绑定。复杂图形、公式对象和浮动布局不能假定被转换器完整支持；应提供教师上传/粘贴题图或导出 PDF 后导入的明确入口。转换后的 HTML 如用于界面显示，按允许列表清洗，保留必要 `sub/sup/img/table`，禁止脚本与危险链接。以上建议不声称项目已经接入这些处理。

### 4.3 OCR：可改善清晰度，不能据此保证化学正确

Tesseract 官方文档指出图像质量、倾斜及版面分割会影响结果，表格识别也有局限；其默认识别目标更接近词句。对化学图文，应把 OCR 当作可能出错的转录。[Tesseract 质量文档](https://tesseract-ocr.github.io/tessdoc/ImproveQuality.html)

建议列为教师校对重点：上下标、离子电荷、元素大小写、反应箭头、条件文字、小数与单位、图表坐标与图例。`Co/CO`、`Cl/CI`、`SO4²⁻/SO₄²⁻` 等为人为设计的易混示例，并非本轮测得的 OCR 错误率。不得凭词典把识别结果“纠正”为看起来常见但原题不存在的物质。

### 4.4 图像理解的显式状态

建议每幅题图记录“已关联、是否送入模型、模型返回说明、教师确认状态”。其中“教师确认”仅确认该说明，不能证明模型所有化学推理正确。

视觉开关关闭时，仍可保留和展示原图，但依赖图片内容的小问应等待教师补充文字或开启支持图片的服务。视觉服务返回不支持、认证失败、请求错误或图片超限时，分别报告，允许教师修复后重试。不要自动移除图片重发并将结果计为同一次成功。

## 5. 化学式显示与导出

MathJax 的 mhchem 扩展支持 `\ce` 化学表达式及 `\pu` 单位表达式，也提供带标签反应箭头等能力。它是排版工具，不是化学正确性或配平验证器。[MathJax 官方 mhchem 文档](https://docs.mathjax.org/en/latest/input/tex/extensions/mhchem.html)

建议：

- 化学式保留原始表达式与显示结果两份信息；普通文本、数学表达式、化学表达式分类型保存。不要用正则把所有数字统一变成下标。
- 可将 `\ce{SO4^2-}`、`\ce{2H2 + O2 -> 2H2O}` 和带条件箭头作为排版回归样例。样例仅检验显示，不能据此验证化学内容。
- 本地打包字体和渲染依赖，避免课堂离线时公式突然消失。语法错误需显示原文及定位，让教师修改；不静默删掉电荷、箭头或反应条件。
- 复杂结构式、键线式、能级图、装置图优先保留原图。不要假设 mhchem 能将任意结构式图片还原成可编辑结构。
- PPT 先确定统一策略：可靠支持的文本使用文本，复杂公式可使用透明图像或适用的矢量资产。每种路径都需验证缩放、换行、上下标、字体及跨页表现；网页渲染成功不代表 PowerPoint 渲染成功。

## 6. 实施优先级与验收建议

| 顺序 | 工作 | 最小验收证据 |
| --- | --- | --- |
| P0 | 独立学科、学段/范围、五模块配置与分项状态 | 化学不混用语言学科任务；失败不覆盖教师已修改或已保存的正确内容 |
| P0 | 原页与题图保存、页码/选区关联、教师确认 | 数字 PDF、扫描 PDF、含多图 DOCX 各有代表样本；跨页题与选项图不丢失 |
| P0 | 图文能力开关和错误语义 | 无视觉能力、鉴权失败、缺图均能定位；没有文本静默替代成功 |
| P1 | 条件/证据/推理与实验字段 | 真实教师检查不满足条件、信息不足、现象与结论混淆、误差方向不确定等样本 |
| P1 | 化学式与公共课件分页 | 屏幕与 PPT 内容/顺序一致；长反应式、装置图、表格可读且不截断 |
| P2 | 变式、教师错因记录与复测 | 没有学生原答不伪造诊断；变式有答案依据；多次独立表现才支持掌握判断 |

验证应分开记录：静态结构检查、模拟 API 测试、真实模型试卷生成、教师学科验收、实际 PowerPoint 打开验收。不能用前两项替代后三项。本次仅完成资料核实和建议文档，以上验收尚未执行。
