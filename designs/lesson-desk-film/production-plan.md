# 讲题工作台宣传短片

已确认：约 2 分 30 秒，16:9，1920×1080，60fps，中文动态字幕，无旁白；白底、圆角、简约。音乐使用 Tobu — Hope（已核实作者 CC BY 3.0 声明）。交付 MP4、封面、字幕、发布文案、可修改动画工程。只提交本任务源码，视频和音乐保留本地，不推送。

## 叙事与设计

主线：把备课材料，变成课堂上的讲解。一份试卷从导入、核对、讲评、编排走向课堂。教师审核与编辑是实际工作流的一部分。使用演示题目和经过简化的功能示意界面，不伪装成录屏或实际 AI 输出。

白 #FFFFFF，墨 #182233，浅灰 #F3F6FA，蓝 #2864EB，青 #087D73，橙 #A64E36（保留应用图标）。微软雅黑系统字体，大标题 82–110px，正文 30–38px，字幕 31px。版面遵循 110px 安全区。圆角按层级使用 18/28/42px。

三种动效：进入 cubic-bezier(.23,1,.32,1)；位置转换及不透明整场接力 cubic-bezier(.77,0,.175,1)；持续进度 linear。进入 0.7–1.0s，主体变形 1.2s，分组错开 60ms。离线逐帧导出保证恒定 60fps。网页预览提供减弱动态选项。

## 分镜（每段 10 秒）

| 时间 | 内容 | 动作与转场 |
|---|---|---|
| 0–10 | 备一节讲评课，要打开多少份材料 | 试卷、答案、笔记围绕课堂问题聚拢 |
| 10–20 | 讲题工作台 | 文件卡归位，应用窗口从卡片中展开 |
| 20–30 | 导入试卷和答案 | 两份文件入槽，PDF/DOCX 标识落位 |
| 30–40 | 扫描识别与原页核对 | 原页与识别稿并排，扫描线和核对标记联动 |
| 40–50 | 整理题目，选定讲解范围 | 一卷拆成题目，选题进入下一步 |
| 50–60 | 英语：从答案讲到理解 | 例句分层高亮，句法与迁移练习展开 |
| 60–70 | 语文：回到文本里讲 | 原文、品读、答题依据互相连接 |
| 70–80 | 化学：题图与推理一起讲 | 装置示意、反应式和实验分析分步出现 |
| 80–90 | 教师编辑与继续生成 | 修改高亮，已完成内容留下，未完成项接续 |
| 90–100 | 按课堂节奏编排 | 内容页横向重排，页码随位置更新 |
| 100–110 | 模板与课件 | 同一内容切换三种排版外观 |
| 110–120 | 放映与 PPT 导出 | 课件铺满课堂画面，再收进 PPT 文件 |
| 120–130 | 模型自主选择 | OpenAI、Claude、DeepSeek 与自定义服务进入设置栏 |
| 130–140 | 本地保存与课件包备份 | 教师内容归档，备份文件落位 |
| 140–150 | 把时间留给讲清楚 | 流程汇合为应用图标、产品名和项目地址 |
